# Data Dictionary

All data is synthetic and generated by `python/generate_data.py`.

## customers
| Column | Type | Description |
|---|---|---|
| customer_id | INTEGER | Primary key |
| customer_name | VARCHAR | Fake customer name |
| age | INTEGER | Customer age (18-80) |
| city | VARCHAR | Customer city |
| join_date | DATE | Date the customer joined the bank |

## products
| Column | Type | Description |
|---|---|---|
| product_id | INTEGER | Primary key |
| product_name | VARCHAR | Checking Account, Savings Account, Credit Card, Personal Loan, Mortgage |
| product_category | VARCHAR | Deposit, Credit, Loan |

## branches
| Column | Type | Description |
|---|---|---|
| branch_id | INTEGER | Primary key |
| branch_name | VARCHAR | Branch name |
| city | VARCHAR | Branch city |

## accounts
| Column | Type | Description |
|---|---|---|
| account_id | INTEGER | Primary key |
| customer_id | INTEGER | FK to customers |
| product_id | INTEGER | FK to products |
| open_date | DATE | Account opening date |

## transactions
| Column | Type | Description |
|---|---|---|
| transaction_id | BIGINT | Primary key |
| account_id | INTEGER | FK to accounts |
| branch_id | INTEGER | FK to branches (customer's home branch) |
| transaction_date | DATE | Date of the transaction (2024-01-01 to 2025-12-31) |
| transaction_type | VARCHAR | Deposit, Withdrawal, Transfer, Payment, Loan Payment |
| amount | NUMERIC | Transaction amount (generic currency units) |
| channel | VARCHAR | Mobile, Web, ATM, Branch, POS |
| fee_amount | NUMERIC | Fee revenue earned by the bank on the transaction |

## Fee logic
`fee_amount = amount x type rate x channel multiplier`, capped at 50. Deposits carry no fee.

## Segmentation (vw_customer_segments)
| Segment | Rule |
|---|---|
| Inactive | No transaction in the last 90 days (relative to the last date in the data) |
| High Value | Top 20% of active customers by value score |
| Medium Value | Next 30% of active customers |
| Low Value | Remaining 50% of active customers |

Value score = 0.5 x percentile rank of 12-month volume + 0.5 x percentile rank of 12-month fee revenue.
